## Desvios do plano
- `role` = nome do grupo de menor id (loadAggregate não garante ordem; "primeiro" tornado determinístico).
- `units` vem de `getSystemUserUnits()` (mesmos ids de `getSystemUserUnitIds()`, com o nome), ordenado por id.
- JSON de erro extra: exceção em onContext responde HTTP 500 `{"error": "..."}`; o JS ignora e deixa a casca sem papel/seletor.
- `unit_id` vazio/≤0 também dá "Unauthorized access to that unit" (setUnit ignoraria em silêncio).
- cv-shell.js observa o DOM (MutationObserver) para montar o select nos slots de páginas carregadas por `__adianti_load_page`; contexto em cache até reload. Com 1 unidade o select fica desabilitado.
- Rótulo acessível do select em pt fixo ("Unidade") no JS, como o placeholder da busca já fixo em layout.html.

## Pendências
- Gate: o admin precisa de novo login para `CvShellController` entrar em `TSession('programs')` (programa 105 criado depois da sessão atual); sem isso engine.php nega e o cartão/seletor ficam vazios.
- `.cv-unit-switch__select` sem regra CSS própria (usa form-select-sm do Bootstrap).
- Troca de unidade não recalcula `tenantid` (resolvido por usuário no login), conforme setUnit existente.
