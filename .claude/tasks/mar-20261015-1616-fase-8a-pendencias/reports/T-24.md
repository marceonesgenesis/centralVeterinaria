    public function onAutosave($param)
    {
        try
        {
            $id = self::encounterIdParam($param);

            if ($id <= 0 || !is_array($param))
            {
                return;
            }

            $context = self::resolveTenantContext();

            TTransaction::open('permission');

            $service = self::makeEncounterService($context);

            $draft = self::postedDraft($param);
            $version = is_string($param['draft_version'] ?? null) && preg_match('/^[0-9a-f]{64}$/', $param['draft_version']) === 1
                ? $param['draft_version']
                : null;
            $seq = max(0, (int) ($param['draft_seq'] ?? 0));

            $result = $service->autosave($id, $draft, $version, self::previousDraft($param));

            TTransaction::close();

            echo '<span class="cv-autosave-result" data-status="' . ($result->saved ? 'saved' : 'conflict')
                . '" data-version="' . CvFormat::e($result->version) . '" data-seq="' . $seq . '"></span>';
        }
        catch (Exception $e)
        {
            TTransaction::rollback();
        }
    }

## Desvios do plano
- Encounter::draftVersion() formata número na escala da coluna (temperature_c/capillary_refill_seconds 1 casa, weight_kg 2, inteiros 0) em vez de só "número como string": sem isso, "12.5" postado e "12.50" relido do DECIMAL dão versões diferentes e todo tick seguinte vira conflito.
- saveDraftIfUnchanged grava também `updated_at = CURRENT_TIMESTAMP(6)` explicitamente, para rowCount() === 1 sempre que a linha casa (MySQL conta só linhas alteradas).
- No conflito do UPDATE condicional, o serviço relê o encontro para devolver a versão atual; em REPEATABLE READ a releitura na mesma transação pode devolver o snapshot anterior — então o "Manter meu texto" pode exigir um segundo clique (o tick seguinte devolve a versão nova). Não grava nada indevido.
- FakeEncounterRepository passou a guardar cópia reconstituída (updated_at do relógio do fake); save() devolve a cópia guardada. Suíte inteira verde, nenhum outro teste afetado.
- Botões de conflito em div `#encounter_autosave_conflict` com display alternado por JS (o atributo hidden seria anulado pelo display:flex inline); "Recarregar a página" usa __adianti_load_page na ação onReload.
- Mensagem de conflito reutiliza a chave existente da T-17 ("The anamnesis was changed in another window..."), como pedido, embora o conflito agora cubra qualquer campo do rascunho.
