## Correção 1
Bloqueante da revisão rodada 1: cookie forjado criava sessão vazia no Redis (`session_write_close()` em landing.php). Ruling: a landing nunca grava sessão.

- `LandingPage::readLogged(?SessionHandlerInterface $handler, string $sessionName, array $cookies, ?string $applicationName): bool`: sem cookie (ou id com caracteres inválidos) retorna `false` sem tocar no handler; com cookie, `session_set_save_handler` + `session_id(cookie)` + `session_start(['read_and_close' => true, 'use_cookies' => false, 'use_only_cookies' => true, 'cache_limiter' => ''])`: só open/read/close, sem write, sem Set-Cookie, sem regenerate. Lê `$_SESSION[APPLICATION_NAME]['logged']`.
- `landing.php` deixa de usar `new TSession`/`session_write_close()` e chama `readLogged(SessionHandlerFactory::createFromEnvironment(), session_name(), $_COOKIE, APPLICATION_NAME)`.
