## Desvios do plano
- Contexto "anônimo novo" por língua: o perfil do Playwright MCP é persistente (após `browser_close`, o `localStorage` ainda tinha `cvp-language=es`). Substituído por `localStorage.clear()` + `sessionStorage.clear()` + `cvp-language=<lang>` + reload antes de cada língua.
- `#lead-vets` com borda vermelha: no envio vazio o cliente nunca marca o select como inválido (`setErr("lead-vets", "")` em `landing.js`; campo opcional com valor padrão), então "Tab até `#lead-vets` → mesma cor" não acontece naturalmente. A regra `.field [aria-invalid="true"]:focus` para select foi verificada com `aria-invalid="true"` sintético no select focado (→ `rgb(179, 65, 46)`); para input, verificada naturalmente (`#lead-name` após envio e `#lead-phone` via Shift+Tab). O select só ficaria inválido por erro do servidor (`showServerErrors`), o que exigiria enviar lead — fora do gate.
